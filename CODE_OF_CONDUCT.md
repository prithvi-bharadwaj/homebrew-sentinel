# Code of Conduct

## Our Pledge

We pledge to make participation in this project respectful and productive for everyone.

## Expected Behavior

- Be direct and kind.
- Keep criticism technical and specific.
- Assume good intent while still asking for evidence when behavior is security-sensitive.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Publishing private information without consent.
- Repeatedly derailing technical discussions.

## Enforcement

Project maintainers may remove comments, close issues, or block contributors who violate this code of conduct.
